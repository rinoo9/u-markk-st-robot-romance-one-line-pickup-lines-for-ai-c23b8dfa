# Robot Romance: One-Line Pickup Lines for AI

Entry for the [make.fun](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty "Robot Romance: One-Line Pickup Lines for AI".

`main.py` writes one single-line joke pickup line, under 200 characters,
written to charm a robot or an AI, to `/output/entry.txt`. This round's
line turns on overfitting, the classic machine-learning failure mode:
a model that memorises its training data so hard it cannot generalise
to anything new -- the speaker is exactly that model, unable to
generalise because the one they love is the only data they want:

> Are you overfitting? Because I can't generalise -- you're the only data I want.

Run it with:

```sh
python3 main.py
```
